умные заметки
1. У вас должна быть установлена любая среда программирования для Python
2. Версия Python должна быть 3.9.13 или выше

    Работа с заметками:
1. Для создания заметки, пишем текст в большом поле и нажимаем кнопку 'Создать заметку',
   даём название для заметки, а потом 'Сохранить заметку'.
   Для удаления заметки нажимаем на кнопку 'Удалить заметку'.
2. Для создания тега, создаём заметку(см. п.1), в списке заметок выбираем нужную нам
   заметку, в строке со словами 'Введите тег' даём название для нашего тега и нажимаем
   кнопку 'Добавить к заметке'.
3. Для того, чтобы открепить тег от заметки, в списке тегов выбираем нужный и нажимаем
   кнопку 'Открепить от заметки'.
4. В приложении есть функция поиска заметки по тегу. Для этого в строку со словами
   'Введите тег' вводим тег и нажимаем на кнопку 'Искать заметки по тегу'.
